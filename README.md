Jawaban Pertanyaan
1. Google Collab digunakan karena merupakan platform berbasis cloud yang memungkinkan pengguna menulis dan menjalankan program Python melalui browser tanpa harus melakukan instalasi Python dan library lainnya secara manual.
2. Library yang digunakan :
   - Numpy digunakan untuk melakukan pengolahan array atau matriks.
   - Pandas digunakan untuk pengolahan data dalam bentuk tabel.
   - OpenCV(cv2) digunakan untuk membaca, merubah dan analisa gambar.
   - PIL/Pillow digunakan untuk membuka dan memanipulasi file gambar.
   - Scikit-image(skimage) untuk pembacaan dan transformasi citra.
   - Matplotlib untuk menampilkan gambar dan membuat visualisasi.

4. [255,255,255] pada citra RGB merupakan satu pixel dengan nilai maksimum pada masing masing chanel RGB yang menghasilkan warna putih, dan sebaliknya jika nilai RGB [0,0,0], akan menghasilkan warna hitam.
5. Pixel merupakan element terkecil penyusun citra digital. semakin tinggi resolusi semakin banyak pixel yang digunakan sehingga gambar dapat menyimpan dan menampilkan detail yang lebih banyak.
